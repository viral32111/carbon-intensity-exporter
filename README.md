This is a Prometheus metrics exporter for the [UK Carbon Intensity API](https://carbonintensity.org.uk).

## 📊 Metrics

* `carbon_generation_mix`: Percentage of electricity generated by each fuel type.
	* `{fuel}`: The type of fuel used for electricity generation (e.g., `solar`).
* `carbon_intensity_forecast`: Forecasted carbon intensity in gCO2/kWh.
	* `{index}`: Human-friendly representation of the forecasted carbon intensity (e.g., `low`).
* `carbon_period_from`: Unix timestamp of the start of the data period.
* `carbon_period_to`: Unix timestamp of the end of the data period (often 30 minutes after the start).

### Global Labels

* `region`: The region of the UK that the forecast applies to (e.g., `North Scotland`).
* `operator`: The DNO *(Distribution Network Operator)* responsible for the region.

## ⚙️ Configuration

All configuration is via environment variables for easy deployment with Docker. See [`.env.example`](/.env.example).

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `CARBON_LOG_LEVEL` | String | Minimum level of logs to print (`debug`, `info`, `warn`, `error`). | `info` |
| `CARBON_HTTP_ADDRESS` | String | IP address to listen for HTTP requests on. | `127.0.0.1` |
| `CARBON_HTTP_PORT` | Number | TCP port to listen for HTTP requests on. | `8080` |
| `CARBON_METRICS_PATH` | String | HTTP path to expose Prometheus metrics on. | `/metrics` |
| `CARBON_METRICS_GO_BUILTIN` | Boolean | Whether to include Go runtime metrics. | `false` |

## 🧰 Development

1. Copy the [`.env.example`](/.env.example) file to `.env` and populate accordingly.
2. Run the application with `go run ./cmd/carbon-intensity-exporter/main.go`.

## 🛠️ Building

Run the relevant build command below, assuming you're on a Linux 64-bit (glibc) system.

### Linux 64-bit (glibc)

```bash
GOOS=linux GOARCH=amd64 \
	go build -o carbon-intensity-exporter-v0.0.0-linux-amd64-glibc ./cmd/carbon-intensity-exporter/main.go
```

### Linux 64-bit (musl)

```bash
CC=x86_64-linux-musl-gcc CXX=x86_64-linux-musl-g++ CGO_ENABLED=1 GOOS=linux GOARCH=amd64 \
	go build -o carbon-intensity-exporter-v0.0.0-linux-amd64-musl ./cmd/carbon-intensity-exporter/main.go
```

### Windows 64-bit

```bash
GOOS=windows GOARCH=amd64 \
	go build -o carbon-intensity-exporter-v0.0.0-windows-amd64.exe ./cmd/carbon-intensity-exporter/main.go
```
